# UXDSL 0.5.0-beta.1

Published from main commit `133f4a854e9992999f9cace4f021780f021b0277`, under npm `latest` at the owner's request. Both `latest` and `beta` point to this prerelease, explicitly requested by the owner. It remains beta software; a dist-tag does not change its maturity.

All five distribution packages use version `0.5.0-beta.1`: `postcss-uxdsl`, `uxdsl-core`, `vite-plugin-uxdsl`, `uxdsl-webpack-loader`, and `uxdsl-cli`.

Read [the migration guide](../../packages/postcss-uxdsl/docs/migration.md) and [changelog](../../packages/postcss-uxdsl/CHANGELOG.md) before upgrading from 0.4 or earlier beta builds. Changes include namespace migration, stricter reference validation, separate theme/component compilation, and explicit Radius/Shadow directive overrides.

Preparation checks: 126 engine tests, core inline-import tests, six consumer cascade tests, generated artifact checks, and the installed-tarball consumer fixture passed. These checks do not establish complete browser or accessibility coverage.
