## What changed

| Story | What it means for a consumer |
| --- | --- |
| MIG-B7-14 | **Fix of a beta.6 defect.** Compiled CSS put the theme's Google Fonts `@import` (and any `@import` you wrote) behind a `:root`, where browsers discard it. ## Known limitations

1. **The packaged base theme does not pass its own contrast gate:** 123
   failing pairs with `base.contrast-exceptions.json` applied (124 without),
   as of 2026-09-28. The remainder is D-8 (`light`/`dark`/`surface` as a tone)
   and D-9 (`warning.main`), both owner decisions scheduled for `rc.1`, plus
   the untoned dark-mode placeholder. The gate pins the exact set, so any
   change in either direction is visible.
2. **Engine findings from this release's work, recorded and not fixed**
   (each in the story that found it):
   - Theme validation accepts non-string values: `palette.primary.main: 5`
     and `spacing: { 1: {} }` build with exit 0 and emit `5` and
     `[object Object]` (MIG-B7-16).
   - `modes: { dark: null }` removes all dark-mode CSS, contrary to the
     migration guide; whether `null` is supported is undecided (MIG-B7-16).
   - `updateBreakpoint` does not rewrite the stylesheet `applyTheme` manages,
     so Density keeps switching at the old threshold; after `updatePalette`, a
     later `applyTheme` reports `ok: true` without a visible change
     (MIG-B7-17).
   - One missing palette reference produces about 20 cascading
     `UXD_REFERENCE_MISSING` errors; a negative breakpoint reports
     `UXD_TYPO_BP` instead of a breakpoint code; `$schema` appears as a
     project leaf in `theme --diff` (MIG-B7-12, MIG-B7-17).
   - No way to apply a rule or directive from a named breakpoint, so a
     directive that should only apply from `lg` needs a literal `@media`.
3. **The shipped contrast exception is stale for the playground's green and
   slate themes** (it matches the default theme only).
4. **Carried over from beta.6:** `applyTheme` refuses structural changes;
   Vite source maps are not advertised; `postcss-advanced-variables` stays
   on `^3`; no `LICENSE` file exists while the READMEs link to one.
