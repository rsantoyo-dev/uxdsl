# The move to one package, `uxdsl`

Stability phase 4 (decision DE-1) merged the five packages into
`packages/uxdsl` and prepared a deprecated re-export of each former name under
`packages/_deprecated/`. The first release of `uxdsl` is `0.5.0-beta.7`; its
publish steps — `uxdsl` itself, the deprecation of the five former names and
the optional shims — are in [0.5.0-beta.7.md](0.5.0-beta.7.md).
