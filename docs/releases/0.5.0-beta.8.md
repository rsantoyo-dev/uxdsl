# UXDSL 0.5.0-beta.8 — release record

**Status: published on 2026-10-08.** The last release of the former
five-package layout. The next release is the one package, `uxdsl@0.5.0-beta.9`
([its record](0.5.0-beta.9.md)).

## What was published

| Package | Version |
| --- | --- |
| `postcss-uxdsl` | `0.5.0-beta.8` |
| `uxdsl-core` | `0.5.0-beta.8` |
| `uxdsl-cli` | `0.5.0-beta.8` |
| `vite-plugin-uxdsl` | `0.5.0-beta.8` |
| `uxdsl-webpack-loader` | `0.5.0-beta.8` |

Built from `0446d7c` (`main` after FEAT-009's beta.7 integration, PR #20), in
the owner's checkout on the branch `docs/stability-audit`. It packages the
repository as it was at that commit — the work its own record called "beta.7",
which was never published under that number — and none of the stability plan
(phases 0–5, the package move, the dependency replacements), which reaches npm
in `uxdsl@0.5.0-beta.9`.

What it contains, relative to `0.5.0-beta.6` (FEAT-009's beta.7 stories):

- The Google Fonts `@import` placed before every other rule, so browsers
  actually load it (MIG-B7-14).
- The typed `uxdsl.config.cjs` that `uxdsl init` writes (MIG-B7-12).
- The upgrade flow: `uxdsl theme --diff` snapshots and the clearer "unchanged"
  message (MIG-B7-15).
- The agent guide packaged at `node_modules/postcss-uxdsl/docs/agent-guide.md`
  (MIG-B7-16).
- The Input `placeholder` following the requested tone on `contained`
  (MIG-B7-01).

### Not run

### After publishing

A smoke test from the registry: install, `uxdsl init` and `uxdsl build`
worked (51 KB of CSS); `npm audit` showed the high findings inherited through
`chokidar@3` and `postcss-advanced-variables`, which `uxdsl@0.5.0-beta.9`
removes.

## How it was published

`npm whoami` was `ricardo.santoyo`. The first publish was refused with
`EOTP`; interactive browser authentication then published all five packages.
The alignment of the `beta` dist-tag was cancelled without changing the tags.
Do not rerun the release script for this version.
