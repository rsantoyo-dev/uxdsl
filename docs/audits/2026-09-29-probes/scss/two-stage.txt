# ts-01 responsive fn
------------------------------------------------------------------------------
.a { padding: xs(1px) md(2px); }

--- after Dart Sass ---
.a {
  padding: xs(1px) md(2px);
}

--- then UXDSL (OK) ---
.a {
  padding: 1px;
}@media (min-width: 768px) {.a {
    padding: 2px;
}
}
